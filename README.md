# Carbon-Flux-Estimation-and-Gap-Filling-Using-ML-Models-

# This project estimates ecosystem carbon dynamics in a paddy field using Eddy Covariance observations and the REddyProc framework.

**Features**
NEE gap-filling using MDS
U* threshold estimation
Flux partitioning (NEE, GPP, Reco)
Net Ecosystem Productivity (NEP) estimation
Phenology-based analysis
Random Forest and Linear Regression modelling
Sensitivity analysis
Diurnal and seasonal flux visualisation


**Technologies**
R
REddyProc
Random Forest
Eddy Covariance Data
Machine Learning
Data Visualisation

**Results**
Automated processing of ecosystem carbon fluxes
NEE, GPP and Reco estimation
Driver-response analysis for Rg, Temperature and VPD
Growth-stage-specific carbon dynamics
